- **Claude Code where you are working.** The container opens Claude Code itself, in a terminal, for the place you are looking at: this project, epic, picked parts and kehikko.
- **Conversations stay with their place.** Connect a conversation to a place with `/kehikot-here`, from inside it, and it reopens there next time; switch epic or parts and the container follows.
- **A clear bar when nothing is connected.** With no conversation connected, a new one starts in the project's folder and a bar at the top says so, with the way to connect one.
- **Every conversation of this kehikko in the View menu.** The header's View menu lists the conversations connected here, and shows whether each is working, waiting for you or finished.
- **Running sessions are not lost.** A session already running somewhere else is attached to rather than started twice, and a renamed or moved project keeps its sessions.
