Kind: feature

- **Adopting a pull request brings its Claude Code conversation along.** When you adopt a pull request that belongs to no epic, Kehikot can now ask which of the project's Claude Code conversations worked on it: the one that opened it, one that worked on its branch, one that mentioned it, or any other in the repository. A conversation that opened it or worked on its branch, and belongs to no other place, is filed under the epic, the same as typing /kehikot-here in it. One that belongs to another place is never moved, and undoing the adoption takes it back only while it is still where Kehikot put it.
- **Kehikot can start a conversation for a task you started.** It starts a new Claude Code conversation with a brief as its first message, filed under the place like any conversation started there, and can show that one conversation on its own while the task runs.
- Only Kehikot itself can ask either. No agent or other module can.

## For agents

- `conversations.finder` and `agent.tasks` (protocol 2.88.0) answer only the host's own server (`vouchHost`). Matches come from what the module already reads of a conversation: the pull requests Claude Code links in its record (`created`), the git branch its rows record (`branch`), its title and first and last prompt (`mentioned`), and the project folder (`folder`). `pushed` is never said: telling a push apart would mean reading the conversation's tool calls.
