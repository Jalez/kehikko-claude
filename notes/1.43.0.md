Kind: feature

- **Edits held to the modules on the kehikko.** A module can now refuse a session's file edits as it already could a shell command: with Worktrees on the kehikko, Claude and its subagents cannot edit files in a project's main checkout or in an installed module's folder, and are told how to make a worktree instead. Commands run as before.

## For agents

- Edit, Write, MultiEdit and NotebookEdit go through the same guard hook as Bash. When a module on your kehikko refuses an edit (for example Worktrees, in a main checkout), make a worktree as its reason says and edit there.
