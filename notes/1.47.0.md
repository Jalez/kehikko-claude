Kind: feature

- **Claude Code outside Kehikot: your choice is now in Claude's settings.** "Use every module's tools in Claude Code outside Kehikot too" and "Use every module's skills in Claude Code outside Kehikot too", with the modules you leave out of each, are Claude's own settings now, for this computer. You find them in Claude's settings and in Kehikot's Settings › Modules. Kehikot keeps Claude Code set up as you choose there.
- What you chose before in Kehikot's Settings is carried over the first time, so nothing you set up changes. If you never chose, both stay off until you turn them on.

## For agents

- Provides `agent.setup` (protocol 2.91.0) as `{ name: 'Claude', program: 'Claude Code', cli: 'claude' }` and declares the four machine, person-only settings (`AGENT_SETUP_KEYS`), kept in `claude/setup.json` beside the module registry. The host reads them with `settings.get` and no project; before this module has its own file it asks the host once at `AGENT_SETUP_CARRIED_PATH`.
