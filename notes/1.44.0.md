Kind: feature

- **Every guard a module declares now reaches Claude.** Each command and file edit is held by one shared check, so a new kind of guard a module on the kehikko declares is held here too, without waiting for this module to learn it. With Worktrees on the kehikko, edits outside a worktree are refused as before.

## For agents

- Bash, Edit, Write, MultiEdit and NotebookEdit all go through the same guard check. When a module refuses a call (for example Worktrees, an edit in a main checkout), its reason says what to do instead: make a worktree as it says and work there.
