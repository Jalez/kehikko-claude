Kind: feature

- **Adopting an item with Claude no longer fails with “did not answer within 8 s”.** Claude now takes the task at once and starts Claude Code afterwards; the dialog closes straight away and the conversation appears in the Claude container as it starts. Before, Claude Code had to boot first, which took longer than Kehikot waits — and the conversation started anyway, unseen.
- **If Claude Code cannot start the task, the Inbox says why.** For example when it is not signed in. The conversation's own page says so too, instead of waiting.
- **A conversation placed with /kehikot-here can now say how its turn ends.** `tell_finished` takes the conversation's key, so its Inbox line shows done, a decision for you, or research complete, like a conversation started from the container.
