Kind: fix

- **Sessions always reconnect to Kehikot.** Every connection a session is given now goes through the Kehikot that started this module, at an address that stays the same when a module restarts, so `/mcp` reconnect works again instead of retrying an address that is gone.
- **Broken connections are repaired.** When the module starts, it rewrites the saved connections of your background conversations that pointed somewhere else, such as a test copy of Kehikot that is no longer running. A conversation that is running says so above the terminal, with a Restart that picks up the fixed connections.
- **Test copies keep to themselves.** Another Kehikot running a copy of your project on the same computer keeps its own conversation files and can no longer write over yours.
