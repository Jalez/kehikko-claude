- **A heavy command held by the queue no longer times out.** When a guard sends a Bash command through the queue (or a dev-server lease), Claude now runs it in the background instead of holding the Bash call while it waits in line, so a long wait no longer cancels the run. You are told when it finishes. A command you already set to run in the background (or not) is left as you set it.
- For agents: Heavy commands you run are queued in the background automatically; wait for the completion notice instead of polling.
